# Call Centre Trends Dashboard

A Power BI project focused on turning call-centre data into a clear operational KPI dashboard.

## Step-by-step workflow

1. Open `CALL CENTRE TRENDS.pbix` in Power BI Desktop.
2. Confirm the data source, refresh status, and reporting period.
3. Review each KPI and check its formula, unit, and denominator.
4. Explore the available service indicators, such as call volume, answer status, wait time, resolution, or satisfaction—include only those actually present in the report.
5. Use filters and slicers to compare time periods or teams where available.
6. Identify operational patterns and verify them against the underlying data.
7. Write a short stakeholder summary with the finding, evidence, and a practical follow-up.

## Tools & skills
