# Call Centre Trends Dashboard

A Power BI dashboard project focused on presenting call-centre KPIs in a clear format for operational review.

## Objective
Translate call-centre data into a concise dashboard that helps stakeholders monitor service performance and identify areas that may need attention.

## Dashboard Scope
The dashboard is intended to visualize relevant KPIs and metrics from the supplied dataset. Depending on the fields available, useful measures may include:
- Call volume and trend over time
- Answered versus abandoned calls
- Response or waiting time
- Resolution and satisfaction indicators
- Performance comparisons by representative, topic, or time period

Only include a measure in the final report if it is supported by the dataset and implemented in the Power BI file.

## Tools
- Power BI
- Call-centre dataset supplied for the project

## How to Review
1. Open the Power BI report file in this repository.
2. Follow any data-source or refresh instructions included with the project.
3. Check KPI definitions, filters, and time periods.
4. Compare the visuals with the questions they are intended to answer.

## Skills Demonstrated
KPI selection, operational reporting, data visualization, dashboard layout, and communicating metrics to stakeholders.
